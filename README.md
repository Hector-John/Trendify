# Trendify

## Description
Trendify is a web application that allows users to manage their orders and view a catalog of shoes. It integrates with Stripe for payment processing and provides a seamless shopping experience.

## Installation Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/trendify.git
   ```
2. Navigate to the project directory:
   ```bash
   cd trendify
   ```
3. Install dependencies for the backend:
   ```bash
   cd backend
   npm install
   ```
4. Install dependencies for the frontend:
   ```bash
   cd ../frontend
   npm install
   ```

## Usage
1. Start the backend server:
   ```bash
   cd backend
   npm start
   ```
2. Start the frontend development server:
   ```bash
   cd frontend
   npm start
   ```
